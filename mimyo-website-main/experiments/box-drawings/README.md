# Box drawings

Prompts used with Gemini 3 Pro Image (`experiments/latch-gemini/prompts/gen.py`) to draw the four "In the pack" items in one line style. References: LHP's technical drawing (`Mimyo-Technical-Drawing-TransBlack.png`, parts straightened onto one axis), the device and teat photos. Outputs were reduced to lines only, recoloured to basalt and exported at one scale (`assets/img/box-*.png`).

Replaced on 2 Nov 2026 by simple line icons (`assets/img/icon-*.svg`); the drawings remain in git history (commit c81852a).
